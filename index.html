Tools

Small tools I wrote while doing offensive security work. Each one is self-contained, with its own README and license. Nothing to install or build.

js-duckfuscator

Deobfuscates and unpacks JavaScript in the browser. Unwraps packer layers, decodes escapes, and reformats the result so you can read it.

JavaScriptDeobfuscation

RDP-Automation

Enables RDP, creates a local admin account, and configures the firewall rules in one run.

PowerShellAccess

nic3r

A nicer ASPX web shell.

ASP.NETWeb Shell

byteclipper

Generates an msfvenom C# payload one-liner and copies it straight to your clipboard.

BashPayloads

port_check

Checks which outbound ports a host can actually reach. Useful for finding the way out of a segmented network.

BashRecon

port_check_PowerShell

The same outbound port check, for Windows hosts where Bash is not an option.

PowerShellRecon

oscp_exam-ai-tips

Scrapes OSCP success stories from Reddit and pulls out the strategies that keep coming up.

PythonOSCP
